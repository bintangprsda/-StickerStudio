# 📋 Sticker Studio - Generator ID Pasien

Aplikasi web modern kelas premium yang dirancang khusus untuk pembuatan stiker identifikasi pasien. Dibangun dengan fokus pada kecepatan, estetika profesional, dan presisi pencetakan untuk lingkungan medis.

## ✨ Fitur Utama

- **💎 UI Glassmorphism Premium**: Antarmuka profesional yang memukau dengan efek transparansi, blur, dan transisi yang halus.
- **💾 Riwayat Penyimpanan Lokal**: Simpan dan kelola data pasien secara langsung di browser Anda menggunakan `localStorage`.
- **✍️ Auto-Save Draft**: Jangan khawatir kehilangan progres. Aplikasi secara otomatis menyimpan draf yang sedang Anda isi saat Anda mengetik.
- **🖨️ Presisi Pencetakan**: Dioptimalkan untuk kertas A4 dengan dimensi stiker presisi **9cm x 2.5cm** dalam tata letak 2 kolom.
- **📑 Manajemen Riwayat**: Muat kembali data lama atau hapus riwayat melalui sidebar penyimpanan yang intuitif.
- **📱 Desain Responsif**: Tampilan yang tetap sempurna di berbagai ukuran layar.

## 🚀 Tech Stack

- **Framework**: [React](https://reactjs.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Styling**: Vanilla CSS (Modern CSS Variables & Glassmorphism)

## 🛠️ Instalasi & Penggunaan

1. **Clone repository**:
   ```bash
   git clone https://github.com/bintangprsda/sticker-studio.git
   ```

2. **Instal dependensi**:
   ```bash
   npm install
   ```

3. **Jalankan dalam mode pengembangan**:
   ```bash
   npm run dev
   ```

4. **Build untuk produksi**:
   ```bash
   npm run build
   ```

## 📐 Spesifikasi Cetak

- **Ukuran Kertas**: A4 (Standard)
- **Ukuran Stiker**: 90mm x 25mm (9cm x 2.5cm)
- **Tata Letak**: 2 Kolom
- **Panduan**: Garis putus-putus (dashed) dengan opasitas rendah untuk panduan pemotongan yang rapi.
